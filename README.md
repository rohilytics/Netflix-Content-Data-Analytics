# 📊 Netflix Exploratory Data Analysis (EDA)

Welcome to the Netflix EDA project! This repository contains a comprehensive exploratory data analysis of the Netflix dataset using Python. The goal is to uncover insights, trends, and patterns in Netflix's content library, including movies and TV shows.

View the Project here https://rohilytics.github.io/Netflix-Content-Data-Analytics/

## 🧠 Project Objectives

- Understand the structure and features of the Netflix dataset
- Clean and preprocess the data for analysis
- Perform exploratory data analysis (EDA) to derive meaningful insights
- Visualize trends in content type, genres, ratings, release years, and more

## 🗂️ Dataset

The dataset used in this analysis contains information about Netflix titles such as:

- **Title**
- **Type (Movie/TV Show)**
- **Director, Cast**
- **Country**
- **Date Added**
- **Release Year**
- **Rating**
- **Duration**
- **Genres (Listed_in)**

> 📌 Note: The dataset was sourced from [Kaggle Netflix Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows).

## 🛠️ Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## 📈 Key Insights

- The distribution of movies vs TV shows
- Most active years for content addition
- Popular genres and content ratings
- Country-wise content production
- Duration patterns for movies and TV shows
- Top contributing directors and actors

## 📎 How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/netflix-eda.git
   ```
2. Navigate to the project directory:
   ```bash
   cd netflix-eda
   ```
3. Open the notebook:
   ```bash
   jupyter notebook "Netflix Exploratory Data Analysis.ipynb"
   ```
